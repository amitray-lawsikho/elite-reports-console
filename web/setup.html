Setup and links

Every API key and every sheet link, in one place. Paste, press Save & test, go green.

Keys are your own: the LeadSquared, Ozonetel, MCube and Acefone keys you paste here are saved for you only — nobody else, admins included, can see them, and everything you run uses them. Sheet and push links are shared: one set for everyone, changed only by a console admin. Saved keys show as dots; leave them alone to keep them, or paste over them to replace. Your own behaviour settings — fetch defaults, breach rules, priorities, retries — are on Settings.
